# Blinkit Product Scraper Using Playwright Network

## 📖 Overview

This project is a Python-based web scraping solution that uses Playwright to capture network responses and extract product information from Blinkit. Instead of relying only on page elements, the scraper monitors API/network traffic to collect structured product data efficiently.

The project demonstrates real-world scraping techniques including browser automation, network interception, JSON response processing, logging, and clean project architecture.

---

## 🚀 Features

* Playwright browser automation
* Network request interception
* API response extraction
* Product data collection
* JSON data processing
* Error handling and logging
* Scalable and maintainable code structure

---

## 🛠️ Technologies Used

* Python
* Playwright
* JSON
* Requests
* Logging

---

## 📊 Extracted Data

* Product Name
* Product ID
* Brand Name
* Product Category
* Price
* Discount Details
* Product URL
* Availability Status
